# S.T.E.P. AI Tutor — Free-tier setup\n\nThis version uses a Cloudflare Worker as the secret-holding backend and the Google Gemini Developer API from Google AI Studio. It does not use Firebase Cloud Functions, so deploying this AI endpoint does not require upgrading Firebase to Blaze.\n\n## 0. Protect the API key\n\nThe Google AI Studio key previously pasted into chat should be treated as exposed. Revoke it in Google AI Studio and create a replacement. Never put the replacement in GitHub or browser JavaScript.\n\n## 1. Check the Gemini free tier\n\nOpen https://ai.google.dev/gemini-api/docs/billing and https://ai.google.dev/gemini-api/docs/rate-limits. Confirm your project is on the Free tier and that the selected model is available to it. Limits vary by model and can change. Do not link a billing account if you want to avoid paid API usage.\n\n## 2. Create a Cloudflare Worker (free plan)\n\n1. Create/sign in to a Cloudflare account at https://dash.cloudflare.com/.\n2. Open Workers & Pages and create a Worker named `step-ai-tutor`.\n3. In the repository root, install Node.js if needed, then run:\n\n```powershell\nnpm install -g wrangler\nwrangler login\nwrangler deploy\n```\n\nDeploy from the repository root. The `wrangler.toml` file configures the Worker entry point and Gemini model. If the dashboard already created a Worker with a different name, either rename it to `step-ai-tutor` or change `name` in `wrangler.toml` to match.\n\n## 3. Add the Gemini API key as a Worker secret\n\nAfter creating the replacement key in Google AI Studio, run:\n\n```powershell\nwrangler secret put GEMINI_API_KEY\n```\n\nPaste the replacement key only into the terminal prompt. Do not add it to `wrangler.toml`, source files, GitHub, or the frontend. Deploy again:\n\n```powershell\nwrangler deploy\n```\n\n## 4. Connect the S.T.E.P. frontend\n\nCloudflare will show a Worker URL similar to `https://step-ai-tutor.YOUR-SUBDOMAIN.workers.dev`.\n\n1. Open `script.js` in the repository.\n2. Find `STEP_AI_TUTOR_WORKER_URL`.\n3. Replace the placeholder `https://REPLACE-WITH-YOUR-WORKER.workers.dev` with your actual Worker URL.\n4. Commit and push that change to `main` so GitHub Pages publishes it.\n\n## 5. Test\n\n1. Open https://tanjbmath.github.io/step/ and sign in with Google.\n2. Join an assignment as a student and open a question.\n3. Try Help Me Start, Check my step, Give me another hint, and Show a similar example.\n4. Test an uploaded question image.\n5. Confirm an account that has not joined the assignment gets denied.\n\n## Free-tier and security notes\n\n- Cloudflare Workers Free currently has a daily request quota; check https://developers.cloudflare.com/workers/platform/limits/ for current limits.\n- Gemini API free-tier model availability and quotas vary. Check the active limits in Google AI Studio. When the free quota is exhausted, requests should fail rather than require you to upgrade.\n- This Worker verifies Firebase ID-token signatures and checks membership against Firestore using the student's token. The Gemini API key stays on the server.\n- The included per-isolate throttle is best-effort, not a globally consistent quota. Gemini's project quota and Cloudflare's plan limits are the main free-tier safeguards. Do not treat this as production-grade abuse prevention.\n- On Google's Gemini API Free tier, prompts and responses may be used to improve Google products; avoid sending confidential student information. See Google's current terms and billing documentation.\n- This Worker does not require Firebase Cloud Functions. You can keep Firebase Authentication and Firestore on your existing setup.\n
